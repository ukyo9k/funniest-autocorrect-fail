Entry for the [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154) bounty on [make.fun](https://make.fun).

## The entry

One line, written by `main.py` to `/output/entry.txt`:

> Great meeting you today, I'll send over the meeting nudes first thing tomorrow morning!

A polite follow-up email to a new client — except autocorrect turned "meeting notes" into "meeting nudes". One wrong word, one very awkward morning.

## How it works

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exits 0, uses no network and reads nothing outside this repository.

## Run it

```sh
python3 main.py
```
